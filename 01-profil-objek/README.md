# 01 — Profil Objek Penelitian

## Identitas objek
| Informasi | Data |
|---|---|
| Nama objek | Keke Craft (nama sementara sesuai penugasan) |
| URL resmi | Belum diberikan / belum diverifikasi |
| Jenis aplikasi | Belum diverifikasi |
| Pengelola | Belum diverifikasi |
| Skala bisnis | Belum diverifikasi |
| Data pengunjung | Belum tersedia |
| Tanggal observasi | Belum dilakukan |

## Kriteria kelayakan
Objek dapat ditetapkan setelah bukti berikut tersedia:
1. Website/aplikasi dapat diakses dan merupakan objek yang benar.
2. Pengelola/pemilik dapat diidentifikasi dari sumber publik atau konfirmasi.
3. Skala usaha tergolong mikro/kecil/menengah atau kategori lain yang dijelaskan dengan indikator terukur.
4. Karakteristik pengunjung didukung analytics yang diberikan pengelola, laporan publik, atau estimasi pihak ketiga yang disebutkan keterbatasannya.
5. Fitur yang diuji dan izin pengujian telah disepakati.

## Catatan validitas
Jangan mengarang jumlah pengunjung, omzet, jumlah pegawai, atau ukuran bisnis. Jika data tidak tersedia, tulis “tidak tersedia” dan jelaskan dampaknya pada pemilihan objek.
