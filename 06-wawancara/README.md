# 06 — Wawancara QA Profesional

## Kriteria narasumber
- QA Engineer / Software Tester / Software Quality Engineer.
- Pengalaman profesional minimal 3 tahun; diverifikasi melalui pernyataan narasumber atau profil profesional yang dapat dirujuk.
- Bersedia diwawancarai online/offline.
- Memberikan persetujuan untuk pencatatan dan penggunaan kutipan.

## Pertanyaan
1. Boleh dijelaskan peran dan pengalaman Anda di bidang QA/testing?
2. Bagaimana Anda menyusun test strategy dan test plan?
3. Kapan memilih black-box, white-box, dan grey-box?
4. Bagaimana menentukan prioritas test case berdasarkan risiko?
5. Bagaimana Anda memilih skenario untuk automation?
6. Bagaimana bug dicatat, diprioritaskan, dan diverifikasi ulang?
7. Bagaimana standar ISO/IEEE digunakan dalam pekerjaan?
8. Apa indikator bahwa pengujian cukup untuk mendukung keputusan rilis?
