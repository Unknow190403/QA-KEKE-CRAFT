# QA Keke Craft — Analisis dan Pengujian Website

Repository ini disiapkan untuk proyek akademik analisis kualitas dan pengujian perangkat lunak pada website Keke Craft.

## Status proyek
- [x] Repository publik dan kerangka dokumentasi dibuat.
- [ ] URL resmi objek penelitian diverifikasi.
- [ ] Skala usaha, kepemilikan/pengelola, dan data pengunjung diverifikasi.
- [ ] Fitur dan alur sistem dipetakan.
- [ ] Test case disusun dari fitur yang benar-benar tersedia.
- [ ] Manual testing dilaksanakan dan bukti disimpan.
- [ ] White-box testing dilaksanakan setelah source code tersedia/diizinkan.
- [ ] Automated testing dijalankan pada target yang disetujui.
- [ ] Wawancara QA profesional minimal 3 tahun dilakukan.
- [ ] Analisis jurnal dan akreditasi SINTA diverifikasi.
- [ ] Laporan akhir dan kesimpulan disusun berdasarkan bukti.

> **Penting:** Repository ini baru berisi kerangka kerja. Tidak ada hasil uji, bug, wawancara, jumlah pengunjung, atau kesimpulan kualitas yang diklaim sudah terjadi. Semua bagian tersebut harus diisi setelah data dan pengujian nyata tersedia.

## Struktur
- `01-profil-objek/`: identitas dan kelayakan objek.
- `02-standar/`: standar resmi yang menjadi acuan.
- `03-test-plan/`: rencana dan ruang lingkup pengujian.
- `04-manual-testing/`: template black-box, white-box, grey-box.
- `05-automation/`: persiapan Playwright.
- `06-wawancara/`: instrumen wawancara QA.
- `07-jurnal/`: telaah jurnal dan validasi SINTA.
- `08-hasil-dan-bukti/`: hasil uji, defect, dan bukti.

## Informasi yang masih dibutuhkan
1. URL website Keke Craft yang benar.
2. Izin pengujian dan batasan yang disetujui pemilik/pengelola.
3. Akses source code bila white-box testing memang akan dilakukan.
4. Narasumber QA yang memenuhi pengalaman minimal 3 tahun.
